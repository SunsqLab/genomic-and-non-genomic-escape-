# Genomic and non-genomic immune escape in cancer

This repository contains the code used for the analyses presented in our study of genomic and non-genomic immune escape in cancer.

##  Code

The code required to reproduce the analyses is organized according to the main analysis sections of the manuscript.

- `S1`: analysis scripts corresponding to Section 1.
- `S2`: analysis scripts corresponding to Section 2.
- `S3`: analysis scripts corresponding to Section 3.
- `S4`: analysis scripts corresponding to Section 4.
- `S5`: analysis scripts corresponding to Section 5.
- `S6`: analysis scripts corresponding to Section 6.
- `S7`: analysis scripts corresponding to Section 7.
- `S8`: analysis scripts corresponding to Section 8.
- `immune_escape_features`: custom functions used for processing and analyzing genomic and non-genomic escape features.


## Data

The datasets used in this study are publicly available from the sources described in the article.

## Software

The analyses were primarily performed in R. Required packages and analysis-specific parameters are provided in the corresponding scripts.
